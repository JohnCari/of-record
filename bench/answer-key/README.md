# Answer key

`doc-195-memorandum-and-order.txt` is the court's Memorandum and Order of September 2, 2011
(Doc. 195), as retrieved from CourtListener:
https://www.courtlistener.com/docket/4195314/granite-southlands-town-center-llc-v-alberta-town-center-llc/

It is the judge's findings of fact and conclusions of law after the bench trial. It is kept out of
`knowledge/`, is never seeded, and is never shown to a drafter: a drafter that could read the
findings would be copying them. It is used for one thing. Where a "sound" row in the test set
states a fact the court itself found, the row says so (`provenance: court-order`, with the finding
number), so that label is a judge's and not the engineer's.
